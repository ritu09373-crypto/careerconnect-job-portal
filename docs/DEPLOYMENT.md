# Deploy CareerConnect

This project includes a `render.yaml` Blueprint for deploying the Express API and Vite frontend to Render.

## Before deployment

1. Create a MongoDB Atlas cluster and database user.
2. In Atlas Network Access, allow connections from Render (or temporarily allow `0.0.0.0/0` while developing).
3. Commit and push the project to GitHub. Do not commit `server/.env`.

## Deploy the API

1. In Render, choose **New → Blueprint** and select the GitHub repository.
2. Render reads `render.yaml` and creates `careerconnect-api` and `careerconnect-web`.
3. Enter the API environment values:
   - `MONGO_URI`: the Atlas connection string.
   - `OPENAI_API_KEY`: optional; needed only for AI job-match scores.
   - `CORS_ORIGIN`: set this after your frontend URL is available, for example `https://careerconnect-web.onrender.com`.
   - `JWT_SECRET` is automatically generated by the Blueprint.
4. Deploy the API and copy its public URL, such as `https://careerconnect-api.onrender.com`.

## Deploy the frontend

1. Set `VITE_API_URL` on the `careerconnect-web` Render service to `https://your-api-name.onrender.com/api`.
2. Redeploy the frontend so Vite includes that value in its build.
3. Update the API service's `CORS_ORIGIN` with the frontend URL and redeploy the API.

## Verify

- Visit the frontend and register a job seeker and recruiter.
- Publish a job, apply for it, and update the application status.
- Open `https://your-api-name.onrender.com/` to confirm the API health response.

Render supports monorepo root directories and static-site publish directories, which this Blueprint uses. See the [Render monorepo guide](https://render.com/docs/monorepo-support) and [static site guide](https://render.com/docs/your-first-deploy).
